# Project Kickoff

## Goal

Develop a cloud-native tax compliance data platform inspired by modern state tax agency data engineering practices.

## Why I Chose This Project

I am interested in data engineering roles in California state government organizations such as FTB.

This project allows me to gain experience with:

- ETL and ELT
- Data modeling
- Data governance
- Cloud architecture
- Analytics engineering
