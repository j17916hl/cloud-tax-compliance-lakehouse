# Project Kickoff

## Goal

Develop a cloud-native tax compliance data platform inspired by modern state tax agency data engineering practices.

## Why I Chose This Project

I am interested in data engineering roles in California state government organizations such as FTB.

This project allows me to gain experience with:

- ETL and ELT
- Data modeling
- Data governance
- Cloud architecture
- Analytics engineering

## Initial Architecture

Source Data
→ Ingestion
→ Validation
→ Transformation
→ Anomaly Detection
→ Case Creation
→ Analytics

### Business Objectives

- Improve data quality through automated validation
- Support data governance and compliance practices
- Create trusted datasets for analytics and reporting
- Simulate enterprise tax administration workflows
- Demonstrate cloud-native data engineering concepts
