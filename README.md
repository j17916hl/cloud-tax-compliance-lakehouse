# Cloud Tax Compliance Lakehouse

A cloud-native data engineering project inspired by enterprise tax administration systems.

## Objectives

- Build cloud-style ETL/ELT pipelines
- Implement Bronze/Silver/Gold architecture
- Demonstrate data governance practices
- Build compliance and anomaly detection workflows
- Support analytics and reporting
